# Intelligent Agro-Management System 

This is a Smart Agriculture project using AI, IoT, and Cloud.

## Phase 1 – IoT Monitoring & AI Crop Recommendation
- ESP32 + soil moisture + DHT sensor monitoring
- Data logging on Blynk Cloud
- AI model for crop recommendation

## Phase 2 – Automation & Plant Health AI
- Automatic irrigation with relay + pump
- Weather-based irrigation skip
- Leaf disease detection (CNN)
- Soil health prediction
